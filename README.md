# ISAACS Cyano Gene Selection

Interactive gene-level map of the *Synechococcus elongatus* UTEX 2973 coding
genome for genome-recoding target selection.

- **Genome**: RefSeq `GCF_000817325.1` (ASM81732v1), taxid 1350461, 2,744,626 bp.
- **Site**: static HTML, published via GitHub Pages from `site/`.
- **Pipeline**: `scripts/` builds `site/data/genes.json` from the genome.

See `docs/notes/tickets/INDEX.md` for active work.
